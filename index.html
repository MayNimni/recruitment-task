Who was actually in the room

A conference draws practitioners and passers-by. Each attendee is measured against the domain of the event they came to — their title, their skills and, for a subject event like a sports-tech summit, their industry. This is scored at ingestion and involves no job: it is what the pool knows before a role exists. Nobody is filtered on it.

What you are looking at

Each card opens a self-contained recruiter view for that role — the ranked shortlist, every score broken into its seven components, and the colleague best placed to make an introduction. Nothing here needs a server or an API key; these are static files, already generated. The matching _matches.csv for each role sits beside its report in output/.

The reports are produced by the pipeline, not written by hand. Any open role can be run. Clone the repository and run python pipeline/main.py run --job <JOB_ID> from its root for whichever role you want, then reopen this page. Setup, the full command list and the design document are in the repository, linked at the top of this page.
