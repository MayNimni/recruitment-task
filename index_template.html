What you are looking at

Each card opens a self-contained recruiter view for that role — the ranked shortlist, every score broken into its seven components, and the colleague best placed to make an introduction. Nothing here needs a server or an API key; these are static files, already generated. The matching _matches.csv for each role sits beside its report in output/.

The reports are produced by the pipeline, not written by hand. To regenerate them — after changing the data, the weights or the scoring — clone the repo and run python pipeline/main.py run --job JOB001 from its root, then reopen this page. See the repository for setup, the full command list and the design document.
